    تغییرات آنلاین برای حساب واردشده ذخیره می‌شوند. اگر آفلاین باشی، این نسخه فعلاً صف آفلاین/تعارض‌گیری پیشرفته ندارد؛ پس بعد از وصل‌شدن وضعیت را بررسی کن.

    اتصال فضای ابری (Supabase)

    این دو مقدار را از Project Settings → API در پروژه خودت بردار. فقط کلید عمومی publishable/anon را وارد کن؛ هرگز service_role یا کلید محرمانه را وارد نکن.

    برای شروع، پروژه Supabase بساز و تنظیماتش را وارد کن.

    حساب کاربری

    اول اتصال پروژه را بررسی کن؛ بعد ثبت‌نام یا ورود انجام بده.
    اگر تازه حساب ساخته‌ای و وارد نمی‌شوی، ممکن است Supabase تأیید ایمیل بخواهد. لینک ایمیل را باز کن و سپس وارد شو. اگر پیام خطا دیدی، متن دقیقش همین‌جا نمایش داده می‌شود.
